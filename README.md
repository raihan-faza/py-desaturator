# py-desaturator

**py-desaturator** is a simple Python script that converts colorful images into black-and-white (grayscale) using the Python Imaging Library (PIL), part of the `Pillow` library. This tool is perfect for quickly removing color from images while preserving their clarity and details.

## Features
- Converts any image to grayscale.
- Simple and lightweight.
- Supports a wide variety of image formats (e.g., PNG, JPEG, BMP).

## Requirements

To use this script, make sure you have Python installed along with the following library:

```bash
pip install -r requirements.txt
```

## Usage

1. Clone or download this repository.
2. Locate your target image and the desired location to save the black and white image.
3. Run the script, you can check below example on how to run it.

### Example

```bash
python conv.py input_image.jpg output_image.jpg
```

- `input_image.jpg`: The colorful image you want to convert.
- `output_image.jpg`: The name of the resulting grayscale image.
